# Cold-review brief

Use before a frame-level proposal or a prior-work comparison goes to the owner. Fill the brackets
and send the whole block to a fresh, read-only agent that has no other context. Do not add
arguments for the proposal. Show the answer to the owner together with the proposal.

```
You are a cold reviewer. You have no context except the files below. Do not trust the proposer.
Read in full:
- <the current claim: open questions, rejection rule, what is not our claim>
- <the record of rejected ideas and retracted sentences, and why each died>
- <prior-work index: titles and summaries, then any file the proposal touches>

Proposal to judge:
<the exact sentence that would go to the owner>

Answer in plain sentences, with no internal labels:
1. Is this a revisit of a dead idea in other words? Name the closest one by its content, quote the
   sentence that killed it, and say whether the proposal differs in substance or only in wording.
2. Which open question of the frame does it serve? If none, say so.
3. The closest prior work on file (quote it) and the one sentence that would distinguish the
   proposal from it.
4. Rejection test. A prior work rejects the proposal only if it states the proposal's message in
   the proposal's setting, or the message follows from it with no new inference. Keyword overlap
   is not enough. For each prior work you cite: quote what it says, name its setting (platform,
   unit, baseline), and answer: does the message follow from it as stated? Which part of the
   message is not in it?
5. The widest scope in which the proposal's sentence could stand, and whether prior work in that
   scope already states it (same test).
6. Verdict: new / revisit / outside the frame.
Read only. Do not edit anything.
```

## Quote check (for a prior-work comparison)

Add to the brief: the comparison text, and the path of each cited source. Ask the reviewer to open
each source and report, per quotation: found word for word or not, the section, the sentence
before and after it, any condition the paraphrase dropped, and any place where "such as" became
"all" or "not found" became "does not".
